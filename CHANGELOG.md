# Changelog

All notable changes to Requiem are documented here. This project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.1] - 2026-11-27

### Changed

- Reduced per-frame work in the starfield by reusing trail coordinates and skipping pointer-distance calculations for stars outside the pointer's reach.
- Build scripts now stage stable Minecraft 1.21.1 releases and generate platform release notes from this changelog.

## [0.1.0] - 2026-11-27

### Added

- The Between, with reverse-played memories, starlit resurrection, and a gradual return to first-person gameplay.
- Unlimited, Limited, Hardcore, and Disabled mortality modes, with per-player overrides and configurable death attribution.
- Death decisions that survive reconnects and server restarts, plus Spectator, Limbo, and dedicated-server ban outcomes.
- Configurable dialogue, effects, sounds, and accessibility options, with optional Incapacitated 2.0.1 compatibility.
- Fabric and NeoForge support for Minecraft 1.21.1 on Java 21.
