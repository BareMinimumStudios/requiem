# Requiem first release

- Enter The Between after death, revisit fading memories, and return through a starlit resurrection.
- Choose unlimited, limited, hardcore, or disabled mortality. Set player overrides and which deaths cost lives.
- Defer a decision through reconnects and server restarts. Configure final death as Spectator, Limbo, or a dedicated-server ban.
- Customize dialogue, effects, sounds, and accessibility settings. Incapacitated 2.0.1 is optional.
